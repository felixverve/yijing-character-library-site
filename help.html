YIJING / GETTING STARTED

从剧本人物，
到有依据的角色设计。

衣境帮你找参考、挑部位、记方案。你决定怎么组合，Codex / WorkBuddy 再根据选定方案整理提示词或继续制作。

① 填角色资料② 匹配参考③ 多图预选④ 确认并交接
只想找一套好看的衣服？直接筛选素材 → 点开图片 → 复制主图下方的提示词即可，无需创建角色。
01

找适合角色的素材

  1. 先选角色。在左侧项目旁点「＋」添加角色；零散角色放「默认项目」。点击角色后，用「编辑角色方案」填写资料。
  2. 已有 AI 提示词？直接粘贴。在人物资料里点「粘贴提示词填资料」，或在编辑窗展开「粘贴提示词，自动整理人物资料」。可插入提纲，也可粘贴零散描述；点「分析并预览」，勾选要填入的字段，再保存角色方案。已有字段默认不替换；识别不确定的内容请手动核对。
  3. 把需求说具体。写明男 / 女 / 儿童、年龄、故事时代、形象与穿衣方向，再补身材、发型和限制。不要只填名字或“漂亮”。
  4. 选择一种匹配方式。「语义匹配」按描述含义找近似参考；「关键词匹配」按描述中的词语、标签与同义词找参考。两种模式互斥。
  5. 用筛选缩小范围。可组合人物类别、现代 / 古装 / 修仙等故事风格、画面风格及外观属性。同组多选满足任一项，不同组需同时满足。
描述示例

成年女性，约 29 岁；现代都市，冷艳酷飒，短发，高挑健美；想找黑色短裙、皮靴与有设计感的配饰。避免幼态脸、夸张肌肉和大面积露肤。

匹配是在找“可参考的方向”，并不表示整张图都符合。若结果太少，先清除其他筛选，再减少非必要条件；若结果有误，以图片为准，不要只看标签。

取消匹配：加载中点「取消匹配」；完成后按钮会高亮为「已选中」，再点一次，或点「退出语义匹配」，即可恢复浏览。关键词匹配也可再点一次退出。
02

多张参考，组合成一个角色

  1. 打开图片详情。主图下方可复制对应提示词；右侧选择要加入的角色。
  2. 勾选参考部位，可多选。例如服装与叠穿、发型与头饰、鞋袜与配饰。选“整体造型”时，不再同时选具体部位。
  3. 写清取舍，再保存预选。例如：“只参考裙型和靴子；不用这张脸；领口提高；保留原角色短发。”同一角色可以选多张图。
  4. 回到「角色预选」检查。在「编辑角色方案」写下最终采用的组合、配色与修改要求，确认后把状态改成「已选定」并保存。

角色资料 = 设计目标

这个人是谁、什么年龄、什么气质，以及不能改变的设定。

角色预选 = 具体参考

从哪些图取服装、脸型或发型，以及哪些地方不能照搬。

收藏只是留着以后看；加入某个角色的预选，才会进入这个角色的交接清单。状态“已选定”代表方案确认，不会自动生成图片。

03

在线使用：导出后交给 Codex

适合直接打开公开网站的用户，打开网站即可使用。

  1. 在网站完成角色资料、预选备注和最终方案，设为「已选定」并保存。
  2. 点击素材列表上方的「导出当前角色清单」，下载这个角色的 Markdown 文件。
  3. 把文件交给 Codex / WorkBuddy，并粘贴下面这段话。没有附件读取能力时，可直接粘贴文件内容。

复制给 Codex · 继续角色设计

请阅读我提供的衣境角色清单，结合角色资料、最终设计方案、每张预选的“参考部位”和“搭配备注”，整理一份完整、可复制的人物设计提示词。
先核对方案是否已选定，指出有冲突或缺失的地方。只参考指定部位，不要把衣服参考的脸当成角色脸，也不要把多张图的所有元素硬拼在一起。
请查看清单中的参考图；若无法访问图片，明确告诉我哪些图没看到，不要假装已看过。未经我明确要求，先不要生成图片。
线上资料只保存在当前浏览器。换设备、换浏览器不会自动同步，清理网站数据可能丢失。导出的清单是单角色交接资料，不是整个工作区备份。仅发送网址，Codex 不能获得你的私人角色和预选。

常见问题

为什么点匹配没有结果？

先检查角色是否有明确的性别与造型描述，再清除来源、搜索词和其他筛选。语义匹配还需要网络和云端服务；失败时可改用关键词匹配或手动筛选。

怎么把选好的参考交给 Codex？

先保存角色方案，再点击“导出当前角色清单”，把下载的 Markdown 文件交给 Codex，并复制本页的交接指令。仅发送网站地址无法带上你的私人预选。

线上匹配要下载大模型吗？

当前默认使用云端语义匹配，不需要下载约 130 MB 的浏览器模型。网页仍需加载素材信息和检索索引，首次使用会受网络影响。

我能删除素材吗？

你可以在“角色预选”中移出不需要的参考，或取消收藏。这只改变你自己的方案，不会删除公开素材库里的图片。

网站会替我保证人物不撞脸、直接生成成片吗？

不会。它提供参考、检索和方案交接。定稿前仍需比较人物骨相、发型、轮廓和服装；生成效果也需要复核。请按素材来源及你使用的生成工具规则使用图片和提示词。
