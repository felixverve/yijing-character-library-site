与本地助手协作
Codex / WorkBuddy 写入需求 → 网站读取并创建设计板 → 你选择素材、编辑方案 → 助手读取本地结果。
  1. 让助手阅读素材库目录中的 docs/本地协作说明.md。
  2. 助手运行 backend/bridge.py，或把项目与角色需求 JSON 放入“协作数据 / 收件箱”。
  3. 点击右上角“读取协作需求”，导入角色，不覆盖已选素材。
  4. 完成选择后点击“编辑角色方案”，填写最终方案、设为“已选定”并保存。
  5. 助手读取“协作数据 / 项目索引.json”，再读取项目方案 JSON 或 Markdown。
这是本机文件协作，不会自动操控其他助手、读取聊天记录或启动图片生成。所有修改自动保存到本地；其他工具更新后，点击“读取协作需求”获取最新内容。
